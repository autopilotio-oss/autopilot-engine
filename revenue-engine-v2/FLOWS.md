# Comment → guide → opt-in → offer → checkout

The full route table is generated by `python3 scripts/revenue/flows.py` into `FLOWS_MAP.md`. Re-run it after any change to keywords, guides or products.

## The journey
1. A post shows one lesson and ends with one ask: "Comment KEYWORD" on IG and TikTok, or the guide link with UTMs on Threads, X and email.
2. ManyChat sends the reply text from `config/keywords.json` (Seb copies it into ManyChat). The reply link should carry `?utm_source=instagram&utm_medium=dm&utm_campaign=<campaign>&utm_content=<content_id>`.
3. The guide page teaches the whole process for free. It has one buy box, for the matching $10 kit and the bundle.
4. Opt-in ("Send me tips") goes to Kit form 10118407 with `source=<guide>` plus the UTM fields (new). Consent is the explicit submit. Kit handles unsubscribes.
5. The Kit sync task puts the lead in exactly one sequence: money, TikTok or business. Never two, never removed.
6. The sequence teaches, then offers the matching kit once, as an option.
7. Gumroad checkout keeps the UTMs (`url_params`). Gumroad delivers the sealed kit PDF, and refunds go through Gumroad.
8. The ledger records `order_paid` and `refund_processed` with no personal data.

## Rules kept
- One CTA per post.
- Value before the offer.
- No bulk DMs.
- Unsubscribe respected (Kit).
- Post-purchase suppression: the welcome email sequences only offer the kit once, but there is no purchaser match yet. That needs a Gumroad → Kit link (Gumroad's Kit integration or a webhook receiver). This is listed under blocked items.
